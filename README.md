First, the UiPath bot retrieves incoming emails from the mail server using the IMAP protocol. From the received email, the subject and body are extracted and displayed using Message Box activities for validation. The bot then checks whether the email contains any attachments using an If condition. If attachments are present, they are saved to a specific local folder on the desktop using the Save Email Attachments activity. The saved documents, such as PDF or DOC files, are read using the Read Text activity to extract their content. The extracted attachment text is summarized using a Generative AI Connector activity.
Next, the email body is also summarized separately using another Connector activity, reducing the content into concise and meaningful lines. Both the summarized email body and the summarized attachment content are then sent to the user through WhatsApp Web automation for quick notification. After this, the language of the received email is detected using the Detect Language activity, and the content is translated into the user’s preferred language using the Translate Language activity. Based on the summarized information, a reply message is generated using the Content Generation activity. User approval is then collected through WhatsApp Web automation to decide whether a reply should be sent or not. If the user approves, the final reply is automatically sent to the recipient using the SMTP Mail activity.
